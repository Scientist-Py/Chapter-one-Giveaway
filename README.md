## 📊 Google Sheets Sync (Google Apps Script)

Add your Google Apps Script URL in [`config.js`](./config.js):
```javascript
googleAppsScriptUrl: "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec"
```

---

## 🚀 Running the Project

Double-click [`index.html`](./index.html) or run with Python:
```bash
python -m http.server 8080
```
Open `http://localhost:8080`.
